<summary>Install Reminder App</summary>

### CLI

Reminder may be used directly in the Command Line Interface (CLI) with a command:

```bash
git clone https://github.com/ngocsang02/ReminderNSang.git
```

### Android Studio

Thực hiện:
  "Open Project"
  "Build"
  "Run Application"

Install app by my phone:
•	Kết nối điện thoại với máy tính 
•	Bật chế độ nhà phát triển
•	Chọn “Cài đặt” -> “Cài đặt bổ sung” -> “Tùy chọn nhà phát triển” 
-> Chọn “Mở khóa OEM”, “Gỡ lỗi USB”, “Cài đặt qua USB”
•	Thực hiện "Run Application" đã nêu ở trên
